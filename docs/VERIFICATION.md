# 1.3.7 本机连接信息

- 新增独立 connections 原生查询，不影响用于发现设备的 networks 数据；每 3 秒刷新、支持手动刷新，离开前台暂停定时刷新、恢复时重新读取，销毁时清理定时器。
- Windows 使用 GetAdaptersAddresses 的连接类型和发送/接收链路速率；Wi-Fi 使用 Native WLAN 的当前连接、信号、信道及缓存 BSS 频率，不主动触发扫描。中文源码使用 UTF-8 编译。
- 原生 Windows 查询单独编译并实际运行：物理以太网报告发送/接收各 1000 Mbps；同时列出系统中的虚拟网卡。此机器无已连接的 Wi-Fi，Windows 无线字段及权限拒绝未实机验证。
- Android 使用 ConnectivityManager / WifiInfo；系统不支持按网络获取 WifiInfo 时，仅在唯一 Wi-Fi 网络下回退 WifiManager。以太网仅在 sysfs 可读时显示协商速率，不将网络带宽估算冒充链路速率。
- Android 16 模拟器实际安装测试：WifiInfo 返回 -50 dBm、2447 MHz（2.4 GHz，信道 8）、发送 1 Mbps/接收 2 Mbps；未请求运行时定位权限即能读取这些字段。模拟器链路值不代表实体无线链路。
- 断开模拟器 Wi-Fi 后旧 Wi-Fi 信息消失，重连后自动恢复；检查手机布局无溢出。实际手机厂商限制、Windows Wi-Fi 网卡及权限弹窗仍待实机验证。
- 系统隐藏字段显示“系统未提供”，不以 0 Mbps、无效 RSSI 或推测频段替代；可显示授权提示。无 GPS 定位调用，不主动扫描热点，不展示或保存 SSID/BSSID。
- 完整 56 项自动测试通过；覆盖 2.4/5/6 GHz（含特殊信道）、未知读数、网络切换清除旧信息、权限操作，以及原有真实 iperf3 集成回归。最终静态分析无问题。
- 版本 1.3.7 / code 12，Windows Release 及 Android 三种 ABI 开发签名 APK。
